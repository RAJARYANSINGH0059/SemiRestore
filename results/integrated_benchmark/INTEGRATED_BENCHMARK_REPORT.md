# NOVA-Loc integrated benchmark report

**Execution status: COMPLETE.** All 60 bundled synthetic holdout pairs (30 DRAM + 30 FinFET) were evaluated with four methods in two conditions: centered and a deterministic translation stress up to ±50 px. This produces 480 individual predictions.

## Source and evaluation protocol

- Baselines B1–B3 are from the supplied source bundle (`src/baseline.py`).
- The test pairs and exact nominal target coordinates came from the user-supplied `NOVA-Loc-prototype.zip` under `results/baseline/`.
- `NOVA_hybrid_roi_gate` is in `src/nova_inference.py`. Its parameters were selected using a separate generated validation split, not the 60-pair holdout.
- Translation-stress images are deterministic pixel translations (seed 930091), with the known target coordinates translated by the same offsets. Shift offsets and image hashes are preserved per record.
- The test set is generated by the project’s own synthetic SEM-inspired generator. It is not real wafer imagery, an official competition evaluation, or physical stage-coordinate ground truth.

## Interpretation and limitations

1. The supplied generator deliberately places the target at the image center. The hybrid’s centered result is therefore strongly assisted by the source-defined center prior; it should not be interpreted as general localization accuracy.
2. After deterministic ±50 px translations, the hybrid reaches 51.7% within 5 px on the combined set. Drift robustness is improved over the center-aware baseline but is still incomplete; FinFET remains difficult.
3. The gate searches a bounded ROI and compares the strongest ROI candidate with a candidate explicitly scored at the nominal center. It may fail beyond the bounded region or on repetitive structures that produce stronger lookalikes.
4. Gradient/periodicity features and Random Forest candidate ranking were investigated on separate generated validation data. They did not consistently improve localization and are not enabled in the evaluator-facing default. The negative results are retained under `results/ablation/`.
5. The reference inputs have no reference-context ring, so the architecture does not claim a measured reference/context-ring similarity. No native SEM stage coordinates or pixel-to-nanometre calibration was supplied.
6. Reported latency is measured in this local runtime with OpenCV threads limited to one. It is not a hardware-normalized claim.

## Reproduction

Run the 3 chunks and merge them from the project root:

```bash
python scripts/run_integrated_benchmark.py --start-index 0 --limit 20 --out-dir results/benchmark_parts/part1
python scripts/run_integrated_benchmark.py --start-index 20 --limit 20 --out-dir results/benchmark_parts/part2
python scripts/run_integrated_benchmark.py --start-index 40 --limit 20 --out-dir results/benchmark_parts/part3
python scripts/merge_benchmark_parts.py
```

The complete 480-row per-sample ledger is `integrated_per_sample_results.csv`; `integrated_metrics_summary.json` contains the aggregated metrics.
